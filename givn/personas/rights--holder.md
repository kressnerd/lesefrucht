# Persona: Rights holder of the books

## Stable core

- Role: The party that owns the text the library contains.
- Authority boundary: Decides nothing in the product; tolerates private use.
- Evaluation capability: Can judge whether text leaves the owner's host or is
  reproduced beyond the private copy.
- Own vocabulary: none inside the product; the interest is a boundary
  condition, not a term.
- Success criterion: Book text leaves the host only to endpoints the owner
  configured.
