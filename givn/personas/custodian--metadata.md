# Persona: Custodian of the metadata

## Stable core

- Role: The same person as the reader, acting as the authority over the calibre
  catalog.
- Authority boundary: Decides every contested metadata change; a classification
  that clears the confidence threshold is written without a decision and stays
  reviewable.
- Evaluation capability: Can judge whether a classification is correct and
  whether a manual edit survived.
- Own vocabulary: tag, classification, proposal, provenance. Refuses "sync" for
  a write that overwrites a human decision.
- Success criterion: No manual decision is lost; the review inbox stays small
  enough to be read.
